# 暗黑挂机 · 地牢探索

参考《暗黑破坏神》的**网页版 2.5D 等距地牢挂机刷装备游戏**。纯 HTML + CSS + JavaScript，**零依赖、零安装**——双击 `index.html` 就能玩，手机浏览器也能玩。

## 怎么玩

1. 双击 `index.html`（Chrome / Edge / Safari）
2. 首页选职业 → 开始冒险
3. 角色会**自动在地牢里跑图、寻路、打怪**，你只需要看着、偶尔点一下
4. 清空整层后走到金色出口进入下一层

## 五职业

| 职业 | 主属性 | 资源 | 定位 | 攻击距离 |
|---|---|---|---|---|
| **战士** | 力量 | 怒气（命中/受击获取） | 近战、高血、AOE | 2.25 格 |
| **游侠** | 敏捷 | 集中值（每秒回复） | 远程、高攻速、单体 | 4.2 格 |
| **骑士** | 力量 | 圣能（缓慢回复 + 受击） | 坦克、反伤、自愈 | 2.25 格 |
| **法师** | 智力 | 魔法（智力相关回复） | 远程、爆发、脆皮 | 5.0 格 |
| **牧师** | 智力 | 魔法（智力相关回复） | 远程、持续伤害、治疗 | 5.0 格 |

每个职业有 **10 个技能**（6 主动 + 4 被动），从中选 **5 个**装配。

## 核心玩法

| 系统 | 说明 |
|---|---|
| **四属性** | 力量→攻击、敏捷→护甲+攻速、体力→生命、智力→魔法+技能效果 |
| **等距地牢** | 每层程序生成 7~10 个房间 + 走廊，34×34 网格 |
| **自动探索** | 自动锁敌、寻路、绕路；迷雾随移动揭开，视野 10 格 |
| **主目标 + 溅射** | 普通攻击只打主目标，溅射伤害由装备词条提供 |
| **主动技能** | 5 个技能位，主动技能消耗资源，公共施法间隔 0.4s |
| **被动技能** | 随等级成长，装上即生效 |
| **装备** | 8 个槽位，5 档品质，词条按部位专属 |
| **精英怪** | 约 12% 概率，血量 ×2.6、必掉装备、金色光环 |
| **远程怪** | 堕落法师 / 血族贵胄会保持距离放弹 |
| **BOSS** | 每层最远房间，血量 ×9 |
| **小地图** | 右上角，点击可展开成大半屏 |
| **成就** | 14 个里程碑，解锁给永久加成 |
| **离线收益** | 关页按战力结算最多 8 小时 |
| **自动存档** | 每 5 秒存 localStorage |

## 装备词条

每件装备从**对应部位**的词条池里随机 1~4 条：

| 部位 | 可出词条 |
|---|---|
| 武器 | 攻击力、暴击率、暴击伤害、攻速、生命偷取、溅射伤害 |
| 头盔 | 生命、防御、暴击率、寻宝、技能冷却缩减 |
| 胸甲 | 生命、防御、寻宝 |
| 手套 | 攻击力、攻速、暴击率、暴击伤害、溅射伤害 |
| 战靴 | 生命、防御、溅射范围、金币获取 |
| 项链 | 暴击率、暴击伤害、金币、寻宝、溅射、冷却缩减、四种资源回复 |
| 戒指 | 攻击力、暴击率、溅射、溅射范围、金币、寻宝、吸血、四种资源回复 |

## 操作

- `1` ~ `5`：释放对应技能位的技能
- `B`：开宝箱　`S`：一键分解
- 点击小地图：展开 / 收起全图
- 侧栏「成就」：查看里程碑
- 侧栏「返回首页」：保存并回主菜单


## 怎么分享给别人玩

**方式一：单文件（最简单）**

```bash
node build.js
```

会生成 `dist/diablo-idle.html`（约 180 KB），把这一个文件发给别人，双击就能玩，不用装任何环境。

**方式二：静态托管（能发链接）**

把整个 `diablo-idle` 目录上传到任意静态托管：

- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支
- **Netlify / Vercel**：直接把文件夹拖进去
- **自己的服务器**：扔到任意 web 目录即可

不需要后端、不需要数据库，纯静态文件。

> 注意：存档用浏览器 localStorage，换设备/清缓存会丢档。想多端同步需要额外做后端。

## 想自己改数值

- 职业 / 技能 / 词条：`js/data.js`
- 成长曲线：`js/core.js` 里的 `monsterHp()` / `expToNext()` 等
- 地图大小：`js/map.js` 的 `MAP_W` / `MAP_H`

改完刷新页面即可（存档结构变化时记得升 `VERSION`）。
