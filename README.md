# 暗黑挂机 · 地牢探索

参考《暗黑破坏神》的**网页版 2.5D 等距地牢挂机刷装备游戏**。纯 HTML + CSS + JavaScript，**零依赖、零安装**——双击 `index.html` 就能玩。

## 怎么玩

1. 双击 `index.html`（推荐 Chrome / Edge）
2. 角色会**自动在地牢里跑图、寻路、打怪**，你只需要看着、偶尔点一下
3. 一次挥砍打中攻击范围里的**所有怪物**，怪物会追着你跑
4. 清空整层后走到金色出口进入下一层，每层地图随机生成

## 玩法机制

| 系统 | 说明 |
|---|---|
| **等距地牢** | 每层随机生成 7~10 个房间 + 走廊，34×34 网格，程序化生成不重样 |
| **自动探索** | 角色自动锁定最近的怪物、自动寻路、打不过会绕路；迷雾随移动揭开 |
| **小地图** | 右上角显示整层轮廓、已探索区域、玩家位置、怪物红点与出口 |
| **AOE 挥砍** | 攻击半径 2.25 格内的所有怪物同时受伤，聚怪越多清得越快 |
| **多怪同屏** | 每层 20+ 只怪物同时活动，仇恨范围内会追击玩家 |
| **BOSS** | 每层最远的房间守着本层 BOSS，血量与伤害都是普通怪的数倍 |
| **装备品质** | 普通（白）→ 魔法（蓝）→ 稀有（黄）→ 传奇（橙）→ 暗金（绿） |
| **随机词条** | 攻击力、防御、生命、暴击率、暴击伤害、攻击速度、生命偷取、金币获取、寻宝几率 |
| **自动装备** | 掉落时自动比较评分，更强就穿上；可关闭改为手动挑选 |
| **开宝箱** | 花金币抽装备，保底魔法品质 |
| **离线收益** | 关掉页面再打开，按战力结算离线期间的金币、经验和装备（最多 8 小时） |
| **自动存档** | 每 5 秒存 localStorage |

## 快捷键

- `B`：开宝箱
- `S`：一键分解

## 文件结构

```
diablo-idle/
├── index.html          页面结构
├── css/style.css       暗黑风界面样式
├── js/
│   ├── data.js         静态数据：品质、槽位、词条池、怪物、场景名
│   ├── map.js          等距地牢生成（房间/走廊/刷怪点）+ BFS 寻路
│   ├── core.js         核心逻辑：多单位战斗、AI、寻路、掉落、装备、存档
│   ├── audio.js        WebAudio 合成音效（无音频文件）
│   ├── ui.js           DOM 渲染 + 等距投影 Canvas 渲染
│   └── main.js         启动、主循环、交互绑定
└── tests/
    ├── core.test.js    地图生成 / 寻路 / 战斗模拟 / 数值平衡
    ├── e2e.cjs         Playwright 浏览器端到端测试
    ├── e2e-save.cjs    存档与离线结算测试
    ├── e2e-ui.cjs      tooltip / 装备 / 分解交互测试
    └── debug.cjs       卡死排查工具
```

node tests/core.test.js     # 逻辑 + 数值模拟（含 1 小时战斗模拟）

## 想自己改数值

打开 `js/core.js`，顶部这几个函数控制全部成长曲线：

```js
function expToNext(level)        // 升级所需经验
function monsterHp(floor)        // 每层怪物血量
function monsterAtk(floor)       // 每层怪物攻击
function monsterExp(floor)       // 每层怪物经验
function monsterGold(floor)      // 每层怪物金币
```

- 攻击范围：`PLAYER_ATTACK_RANGE`
- 移动速度：`PLAYER_SPEED`
- 怪物密度：`js/map.js` 里 `rint(3, 6)`
- 地图大小：`js/map.js` 里的 `MAP_W` / `MAP_H`

改完刷新页面即可生效（存档里的旧装备数值不会重算，想重来就点「重置存档」）。
